# Google Sign-In & Google APIs
- [google-api-nodejs-client](https://github.com/googleapis/google-api-nodejs-client) | Google’s official Node.js client for Google APIs, including OAuth 2.0 support. **Best general-purpose API client.**
- [vue3-google-signin](https://github.com/wavezync/vue3-google-signin) | Vue 3 integration for Google Identity Services; recently updated and MIT-licensed. **Best if you use Vue.**
- [oauth2-proxy](https://github.com/oauth2-proxy/oauth2-proxy) | Google sign-in and other OAuth providers for protecting web apps behind a proxy. **Useful for app access/login, not a Google API client.**
- [google-workspace-mcp](https://github.com/aaronsb/google-workspace-mcp) | OAuth-authenticated Gmail, Calendar, and Drive access through an MCP server. **Good Workspace integration example.**
- [js-samples]](https://github.com/googlemaps/js-samples) | Google’s JavaScript Maps API samples.
- [js-api-samples](https://github.com/googlemaps-samples/js-api-samples) | Google Maps JavaScript API documentation examples.
